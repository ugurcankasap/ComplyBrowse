Layer Guide (L1 - L2 - L3)

L1 - Managed Policy

Enterprise-managed policy layer (GPO, MDM, registry, policies.json). This is the highest-priority evidence layer.

L2 - User Preference

User/profile settings layer (for example prefs.js). Even when compliant, enforcement may be weak because users can revert it.

L3 - Runtime Arbiter

Runtime behavior and process evidence layer. Used to detect drift/bypass and validate the final decision.
