# Roadmap

This roadmap tracks the public release direction after the v1.1.0 macOS
platform milestone.

## v1.2.0 - Dynamic Evidence

- Record expected, observed, evidence, and confidence fields.
- Persist per-control artifacts for auditability.
- Apply value-based verification with explicit verdicts.

## Next - v1.3.0 Candidate

- Expand managed-policy and runtime evidence coverage.
- Improve cross-platform fixture coverage for Windows and macOS.
- Publish a stable package and CLI installation workflow.
- Keep CI gates aligned across the source and public upload projects.

Roadmap items are planning targets, not release commitments. The release
policy and versioned release notes remain authoritative for shipped behavior.
