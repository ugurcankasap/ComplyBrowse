# v1.1.0 - macOS Platform Support

## Summary
This release extends the assessment surface to macOS with fixture-validated
evidence collection, and hardens the publish path for shareable reports.

## Highlights
- Chrome and Firefox macOS evidence collection with platform-aware report separation and TCC-aware `NOT_ASSESSED` handling.
- Limited Safari macOS support based on CIS Apple macOS Benchmark references, with TCC-gated preferences and no runtime arbiter.
- Strict public-report sanitization for macOS paths, profiles, device identifiers, MDM metadata, extension IDs, and raw plist content.
- Automated publish-safety gate that blocks private report outputs and machine-specific evidence markers before release.
- Reference-catalog result names now show only the control title; CIS identifiers stay in the dedicated reference-control field.
- Mermaid architecture diagram for L1-L3 evidence precedence and L4 provenance, plus an end-to-end control contribution guide.
- `integrated_report.html` is the canonical viewer; `dashboard.html` redirects to it.

## Validation
- PowerShell lint gate: 0 findings under the shared `PSScriptAnalyzerSettings.psd1` profile.
- Verification engine self-validation: truth table and scenarios pass.
- Publish-safety gate: 0 violations.
- Python contract tests: 36 tests pass; coverage above the 60% gate.
- Ruff lint: clean.
- macOS launcher syntax check: clean.

## Known Limitations
- macOS CI runs deterministic synthetic fixtures only; GitHub-hosted runners are not MDM-enrolled, so live MDM/L1 collection stays endpoint-only.
- Safari coverage is limited and has no runtime arbiter.
- Live browser result generation and the verification regression gate still require a Windows endpoint.

## Upgrade Path
- No report schema breaks. Windows workflows are unchanged.
- macOS operators start from `run_macos_security.command`.
