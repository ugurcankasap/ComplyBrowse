# v1.2.0 - Dynamic Transition Milestone (planned)

> Planning draft. This version is not released and not tagged. Shipped behavior
> is defined by [CHANGELOG.md](../CHANGELOG.md) and the released notes in this folder.

## Summary
This release introduces the first dynamic evidence model for critical controls.

## Highlights
- Critical controls enriched with expected vs observed outputs.
- Evidence metadata fields (type, confidence, reason, manual requirement).
- Initial run_id-based artifact storage and evidence path tracking.
- Viewer support for evidence details.

## Validation
- Critical-control outputs verified with evidence fields.
- Artifact snapshot creation verified.

## Known Limitations
- Dynamic model currently starts with critical controls and is expanded in later iterations.

## Next Steps
- Extend artifact and dynamic evidence model to Chrome/Firefox runners.
- Add richer evidence dumps for FAILED and UNKNOWN outcomes.
