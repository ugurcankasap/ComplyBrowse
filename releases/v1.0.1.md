# ComplyBrowse v1.0.1

This patch release strengthens result integrity and establishes the repository's contributor workflow.

## Reliability

- Required browser control catalogs now fail fast when missing or unparseable.
- QA contracts preserve the published Edge, Chrome, and Firefox catalog coverage.
- Edge observations no longer become failures without conclusive evidence.
- Proxy bypass verdicts use actual `ProxyMode` and `ProxyBypassList` values.

## Community

- Structured bug and feature request forms.
- Private security-report routing through the security policy.
- Pull request checklist and default code ownership.
- Contributor conduct policy and repository status badges.

## Validation

- Python QA contract suite: 19 tests.
- Edge full pipeline: 57 controls with zero integrity-audit defects.
