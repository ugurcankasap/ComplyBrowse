# Code of Conduct

## Our standard

ComplyBrowse contributors must communicate respectfully, review technical claims on their evidence, and make participation welcoming regardless of background or experience.

Examples of acceptable behavior include:

- Giving specific, constructive feedback.
- Separating technical disagreement from personal criticism.
- Protecting sensitive endpoint and organization data.
- Correcting mistakes transparently when evidence changes.

Harassment, discrimination, threats, personal attacks, deliberate disclosure of private information, and sustained disruption are not acceptable.

## Scope

This standard applies in repository issues, pull requests, reviews, discussions, and other project spaces. It also applies when someone publicly represents the project.

## Reporting and enforcement

Report conduct concerns privately to the repository owner through their GitHub profile. Do not use a public issue when a report contains private or sensitive information.

Project maintainers may edit or remove contributions and may temporarily or permanently restrict participation when behavior violates this standard. Reports will be reviewed as privately and fairly as practical.
